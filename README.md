# SOURCEWISE — Academic AI Research Workspace

> **Trace Every Claim. Build Grounded Research.**
> A distinctive, production-oriented AI research workspace for university students, thesis writers, and literature reviewers.

---

## 1. Product Vision & Architecture

SOURCEWISE combines three interconnected experiences for students and scholars:
1. **Research Desk & Project Management:** Manage literature reviews, thesis inquiries, notes, and academic papers.
2. **Signature Split-Pane PDF Reader:** Read papers, navigate physical pages, inspect sentence-level chunks, and click verified citations to instantly scroll to and highlight exact source passages.
3. **Research Canvas & Synthesis Tools:** Connect papers, concepts, findings, and author limitations into an interactive knowledge graph, compare literature across custom dimensions, and explore evidence-backed research gaps.

Every claim generated by the system is checked against stored physical page text. Hallucinated quotes and fabricated page references are flagged and rejected by the citation verification engine.

## 3. Distinctive Visual Identity

- **Surfaces:** Warm ivory, parchment, and paper surfaces (`#FBF9F5`, `#F5F2EB`, `#EFECE4`) inspired by contemporary academic journals and reading desks.
- **Typography:** `Newsreader` (editorial serif with proportional figures) paired with `Geist` (clean geometric interface sans-serif) and tabular monospace for citation badges and physical page coordinates.
- **Accents:** Muted botanical sage (`#3E5948`, `#2C4234`) for navigation and verified states; warm amber (`#B45309`, `#FEF3C7`) for active citations and passage highlights.
- **Anti-patterns avoided:** No generic purple-to-blue SaaS gradients, no nested card clutter, no fake metrics/KPIs, and no decorative animations that delay reading.

## 4. Key Workflows & Features

### 4.1 Split-Pane PDF Reader & Contextual Assistant
- Left pane: Page-by-page physical PDF reader with zoom controls, page jumping, and passage highlights.
- Right pane: Grounded Gemini / rule-synthesizer dialogue. Click any citation badge `[1]`, `[2]`, `[3]` to immediately jump to that physical page and highlight the verified source excerpt.

### 4.2 Paper Library & PDF Ingestion
- Upload academic PDFs up to 30MB with SHA-256 duplicate detection.
- Heuristic bibliographic metadata parser extracts Title, Authors, Year, Journal/Venue, and DOI.
- Sentence-level chunker indexes text with physical page numbers and character offsets.

### 4.3 Literature Comparison Matrix
- Multi-paper comparison across: Research Objective, Methodology, Dataset/Participants, Key Findings, and Stated Limitations.
- Explicit status marking: distinguishes directly reported claims from unaddressed fields (*"Not reported in source text"*).

### 4.4 Research Canvas
- Visual conceptual synthesis map featuring interactive nodes: Papers, Concepts, Findings, Methodologies, and Potential Gaps.
- Semantic typed edges: `supports`, `contradicts`, `extends`, `similar_method`, `identifies_limitation`.
- Detail inspector drawer and source document navigation.

### 4.5 Research-Gap Explorer
- Synthesizes candidate research gaps directly from author-stated limitations.
- Displays supporting passages alongside contradictory evidence.
- Explicit epistemic uncertainty notices and recommended step-by-step academic validation plans.

### 4.6 Notes & Bibliographic Reference Manager
- Structured notes tagged by chapter or topic, linked to specific papers and physical page numbers.

## 5. Getting Started & Local Development

### Prerequisites
- Node.js 18+ (tested on Node v24.14.1)
- npm or bun

### Installation
```bash
git clone <repo-url> sourcewise
cd sourcewise
npm install
```

### Environment Configuration
Copy `.env.example` to `.env.local`:
```bash
cp .env.example .env.local
```
Provide your optional Supabase and Gemini credentials:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
GEMINI_API_KEY=your-gemini-api-key-here
GEMINI_MODEL=gemini-2.5-flash
```
*(Note: If Supabase or Gemini keys are omitted, SOURCEWISE automatically runs in high-fidelity local scholar mode using its resilient local storage adapter and deterministic evidence grounder).*

### Running Tests
```bash
npm run test
```

### Production Build & Launch
```bash
npm run build
npm run start
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## 6. Database Migrations & Security

The complete PostgreSQL schema and Row Level Security policies are located in:
`supabase/migrations/20261015000000_init_sourcewise.sql`

Includes:
- RLS policies enforcing strict ownership across `profiles`, `research_projects`, `documents`, `document_pages`, `document_chunks`, `chat_conversations`, `chat_messages`, `message_citations`, `research_notes`, `comparison_matrices`, `research_canvases`, and `research_gap_analyses`.
- Private Supabase Storage bucket policies (`sourcewise_papers`) restricting PDF access strictly to the uploading scholar.
- Foreign key constraints and multi-column indexes for fast provenance lookup.
